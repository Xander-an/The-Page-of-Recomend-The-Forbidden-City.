# English presentation script

建议：预先熟悉代码，边演示边讲解。以下时间仅为参考；按自己的语速控制在 6–8 分钟，总长不要超过作业规定的 10 分钟。方括号中的文字是操作提示，不需要读出。姓名请替换为本人姓名。

录制前：把本人的照片作为叠加图层放在录屏画面右上角。不要用网页右上角的装饰印章代替个人照片。准备好浏览器和代码编辑器，检查麦克风、网页图片、视频与地图网络。可使用熟悉的录屏软件添加图片叠加层。

## 0:00–0:45 Introduction and banner

[Show the top of the website.]

Hello, my name is [your name]. Today I am presenting my historical place website about the Forbidden City in Beijing.

I chose this place because its architecture and history make it an interesting subject for a visual website. My page is called The Forbidden City: A Journey Through Time.

I used HTML5 to structure the page and CSS to style it. I also used a small amount of JavaScript for the video and map tabs and the navigation highlight.

The banner uses a local photograph of the palace. A dark gradient makes the text easier to read. I chose palace red, warm cream, and gold to connect the design to the architecture.

## 0:45–1:45 Navigation and introduction

[Hover over the navigation links, then click The story.]

The navigation bar has four links. They jump to different sections on the same page, so visitors do not need to open another page. The header stays at the top while the visitor scrolls.

Here is the introduction. It uses headings, paragraphs, an image, and a link to the official museum website. The palace was completed in 1420, and the Palace Museum opened in 1925.

[Open index.html in the editor.]

The document starts with the HTML5 doctype. In the head, I set the character encoding, the page title, and the viewport. The viewport helps the page fit different screen sizes.

In the body, I use semantic tags such as header, nav, main, section, and footer. The navigation links have addresses like hash story. The matching section has the ID story. This is how the anchor navigation works.

## 1:45–2:40 Attractions and images

[Return to the browser and show Must-see places.]

This section introduces three places: the Hall of Supreme Harmony, the Imperial Garden, and the Corner Towers. I use an ordered list with ol and li tags because these are related attractions.

Each item has a photograph, a heading, and a short description. When I move the mouse over an item, the photo grows slightly. This gives the page a simple interactive effect.

[Show the attraction-list CSS rule.]

I use CSS Grid to place the three items in columns on a large screen. The gap property adds space between the items. The images use object-fit cover, so they fill their frames without being stretched. Each image also has alternative text for accessibility.

## 2:40–3:45 Travel table and bonus hover effects

[Show Journeys. Move the pointer over different table rows.]

This is the travel package table. It compares three example journeys. Each row shows a package name, a duration, included activities, and a sample price. The note explains that these are student project examples, rather than real museum offers.

[Show the table HTML and the tbody tr:hover CSS rule.]

The table uses the table, caption, thead, tbody, tr, th, and td tags. The caption describes the table. The th elements identify the column headings and the package names. The scope attributes make the relationships clearer for screen readers.

For the bonus challenge, I added a hover effect to the table rows. The background changes when the mouse moves over a row. I also added a color change and an underline effect to the navigation links. CSS transitions make these changes smooth.

## 3:45–4:45 Video and map

[Show Explore & visit. Show the video, then click Find your way.]

This section contains two embedded resources. The first is a Bilibili video from the Palace Museum's official account. The second is a Baidu Map showing the museum's location.

[Show both iframe tags in index.html.]

Both resources use the iframe tag. Each iframe has a title to explain its content. The video has autoplay turned off. The surrounding frame uses an aspect ratio of sixteen to nine, so the media area keeps a consistent shape.

The tabs are buttons. A short JavaScript function changes which panel is visible and updates the selected state. The arrow keys also switch between the tabs.

These external resources need an internet connection. I included links to the original sites so visitors have another way to open them.

## 4:45–5:45 Footer and responsive layout

[Show the footer. Then demonstrate a narrower browser window if convenient.]

The second bonus challenge is the footer. It includes the museum's public email address, its address, and a link to its Bilibili social media content. I clearly identify this website as an independent student project.

The footer also includes expandable source information and photo credits. The photos are saved locally, and the credits link to their authors and licenses.

The page is responsive. On a narrow screen, the attraction list becomes a single column. The introduction and visit sections also stack vertically. The table can scroll horizontally, so its text does not have to become too small.

## 5:45–6:45 CSS explanation and finish

[Show styles.css, especially :root, a Grid rule, a hover rule, and a media query.]

At the top of the CSS file, I define variables for the main colors and fonts. This keeps the design consistent and makes it easy to change the theme.

I use Flexbox for the header and navigation, and Grid for the main content layouts. Margins and padding create space between elements. Serif fonts give the headings a historical feeling, while a simple sans-serif font keeps the body text readable.

Media queries adjust the layout for tablets and phones. I also provide visible keyboard focus styles and respect the reduced motion preference.

My website includes a banner, navigation, an introduction, images, a styled attraction list, a travel table, embedded video and map, and a footer. It also includes both bonus features.

Thank you for watching my presentation.
